隐私政策

生效日期：2026 年 10 月 4 日
发布者：Shawn
联系方式：ly88321@gmail.com

LanBox 不包含广告、分析 SDK 或开发者运营的云端服务，也不会向发布者收集或上传个人数据。

LanBox 专业版购买由 Apple 的 App Store 和 StoreKit 处理。发布者不会取得用户的银行卡或付款资料；App 仅从 StoreKit 读取专业版权益状态。

用户启动服务后，LanBox 会在当前局域网内监听 HTTP 和/或 SMB 连接。用户选择连接的局域网设备可按照设置的权限读取或写入 App Documents 目录。传输仅发生在用户设备与局域网客户端之间，发布者不会接收传输内容。

启用“共享手机相册”后，LanBox 会请求照片权限，并通过 PhotoKit 提供只读虚拟目录。照片和视频仅在局域网客户端请求打开时按需读取，不会为了共享而完整复制相册，也不会上传给发布者。用户可随时在系统设置中撤销照片权限。

账号、密码、App 密码和偏好设置保存在设备本地。敏感凭据使用 iOS Keychain。Face ID 验证由系统完成，LanBox 不会获得或保存面部数据。

LanBox 进入后台后停止文件服务。用户可在 LanBox 或“文件”App 中删除本地文件，也可通过卸载 App 删除其本地数据。

HTTP Basic Authentication 不提供传输加密。请仅在可信局域网中使用 HTTP。

Privacy Policy

Effective date: October 4, 2026
Provider: Shawn
Contact: ly88321@gmail.com

LanBox contains no advertising or analytics SDK and uses no provider-operated cloud service. It does not collect or upload personal data to the provider.

LanBox Pro purchases are processed by Apple's App Store and StoreKit. The provider does not receive payment-card or billing details; the app only reads the Pro entitlement status supplied by StoreKit.

When sharing is started, LanBox listens for HTTP and/or SMB connections on the current local network. Local network clients selected by the user may read or write the app's Documents directory according to configured permissions. Transfers occur directly between the user's device and local network client; the provider does not receive their contents.

If Photo Library sharing is enabled, LanBox requests photo access and presents a read-only virtual directory backed by PhotoKit. Photos and videos are read on demand only when a local client opens them. The library is not duplicated for sharing or uploaded to the provider. Photo access can be revoked in system settings.

Account credentials, app passcode, and preferences remain on the device. Sensitive credentials use the iOS Keychain. Face ID authentication is performed by the system; LanBox does not receive or store facial data.

File services stop when LanBox enters the background. Users can delete local files in LanBox or the Files app, or remove local app data by uninstalling LanBox.

HTTP Basic Authentication does not encrypt network traffic. Use HTTP only on a trusted local network.
